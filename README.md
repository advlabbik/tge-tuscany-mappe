# TGE Tuscany 2026 — mappe per le autorità

Pagine statiche (GitHub Pages da `main`, https://advlabbik.github.io/tge-tuscany-mappe/)
con la traccia del The Grand Escape Tuscany 2026 (10-16 ottobre), da mandare
agli enti al posto del link RideWithGPS. Nessun build step: ogni pagina porta
le coordinate dentro di sé.

| File | Per chi | Contenuto |
|---|---|---|
| `livorno.html` | Questura di Livorno | percorso completo (route RWGPS 54159356 del 5/10/2026, 589 km, tutti i 18.318 punti) con evidenziati i tratti nei comuni di Bibbona (km 542,3-548,8) e Castagneto Carducci (km 548,8-568,5); confini di Bibbona, Castagneto e Cecina (il percorso non entra a Cecina) |

Confini comunali da OpenStreetMap (Nominatim), progressive calcolate sulla
traccia: possono scostarsi di qualche centinaio di metri dal contachilometri.
Il PDF con l'elenco delle strade sta fuori dalla repo.
